# 部落管家 APK 打包说明

这是一个安卓 WebView 封装工程，内置了完整的「部落管家」App（离线可用）。

## 方式一：GitHub 云编译（推荐，不用装任何软件）

1. 注册 / 登录 [github.com](https://github.com)；
2. 点右上角「+」→「New repository」新建仓库（名字随意，选 Public，不要勾选自动生成 README）；
3. 点「uploading an existing file」，把本工程的**全部文件和文件夹**拖进去上传
   （注意：要上传的是 `app`、`gradle`、`.github` 这些**文件夹本身**，以及 `build.gradle`、`settings.gradle` 等文件；GitHub 网页上传支持直接拖文件夹）；
4. 上传后进入仓库的「Actions」标签页 → 左侧点「Build APK」→ 右侧点「Run workflow」→ 运行；
5. 等 2~5 分钟变绿后，点进这次运行记录，下方 Artifacts 里下载 `clan-butler-apk`；
6. 解压得到 `app-debug.apk`，传到手机上安装（安装时允许「未知来源」即可）。

## 方式二：Android Studio 本地编译

1. 安装 Android Studio（官网下载，安装时默认选项即可）；
2. 打开工程文件夹（选择本目录）；
3. 如果提示 Gradle 相关问题，按提示让 Studio 自动修复/下载 Gradle 8.7；
4. 菜单 Build → Build App Bundle(s) / APK(s) → Build APK(s)；
5. 产物在 `app/build/outputs/apk/debug/app-debug.apk`。

## 说明

- App 内容内置在 `app/src/main/assets/index.html`，**离线可运行**，数据存手机本机；
- 「📷 图片识别采集」需要联网下载 OCR 模型（首次约 15MB），之后有缓存；
- 以后想改 App 内容：直接替换 `assets/index.html`，重新编译即可；
- 目前是 debug 签名，自己用完全没问题；要上架商店才需要正式签名。
